# UI Screenshots

This directory contains screenshots of the RAG Knowledge Assistant UI.

## Required Images

1. **rag-ui-query.png** - Screenshot showing the query interface with:
   - Question input field
   - Answer with citations
   - Top K slider

2. **rag-ui-ingestion.png** - Screenshot showing the ingestion interface with:
   - Folder path input
   - Ingest button
   - Success message after ingestion
   - List of indexed documents

## Adding Screenshots

1. Save your screenshots in this directory with the names above
2. Run: `git add docs/images/*.png`
3. Commit: `git commit -m 'Add UI screenshots'`
4. Push: `git push`
